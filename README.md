# Visión Artificial con OpenCV

Siete prácticas de Visión Artificial con OpenCV en C++, acompañadas de comparaciones entre las imágenes originales y sus resultados.

| Actividad | Métodos |
|---|---|
| [Lectura de imágenes](01_lectura_imagenes/) | Lectura, conversión de color y separación de canales BGR |
| [Transformaciones geométricas](02_transformaciones_geometricas/) | Traslación, rotación, escala, reflexión, transformaciones afines y perspectiva |
| [Calibración de cámara](03_calibracion_camara/) | Detección de esquinas, calibración y corrección de distorsión |
| [Filtros espaciales](04_filtros_espaciales/) | Suavizado, enfoque y detección de bordes |
| [Filtros en frecuencia](05_filtros_frecuencia/) | Transformada de Fourier, máscaras espectrales y reconstrucción |
| [Histogramas y umbralización](06_histogramas_umbralizacion/) | Histogramas, ecualización, Otsu y umbralización adaptativa |
| [Morfología matemática](07_morfologia_matematica/) | Erosión, dilatación, apertura y cierre |
